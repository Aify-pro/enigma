Aucun calendrier configuré

Configurez un calendrier pour chaque salle directement dans Admin → Salles.

  1. Ouvrez Google Calendar → Paramètres de l'agenda
  2. Section Intégrer l'agenda
  3. Copiez l'URL de l'<iframe src="…"> → collez dans URL iframe de la salle
  4. Copiez l'adresse publique au format iCal → collez dans URL ICS de la salle

Iframe non configurée

Ajoutez une URL iframe pour cette salle dans Admin → Salles.
